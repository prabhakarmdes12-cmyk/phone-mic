## 4. Discovered Bugs, Anomalies, or Edge-Case Observations (If Any)

- **ID**: QA-01
- **Severity**: P3 - Minor
- **Description**: Adaptive feedback notch is deployed with Q = 8.0 while the specification (Suite 2.2) requires Q = 12 notch attenuation.
- **Reproduction Steps**: 1) Open `app/src/main/cpp/native-audio-engine.cpp` `processDsp()` feedback branch. 2) Observe `feedbackNotchFilter_.setNotch(sampleRate_, estFreq, 8.0f);`. 3) Compare with mission spec "deploys Q=12 notch attenuation".
- **Root Cause & Recommended Remediation**: Coefficient constant drifted from spec. Change to `setNotch(sampleRate_, estFreq, 12.0f)` (narrower, more surgical notch) or formally amend the spec to Q=8 after acoustic tuning; add a JUnit/native unit test asserting the deployed Q.

- **ID**: QA-02
- **Severity**: P2 - Major
- **Description**: The Platform Java fallback engine implements **no** howling feedback suppression: `JavaAudioEngine.setFeedbackSuppression(enabled) = Unit` ("No adaptive notch in fallback"). On Android 11 (API 30) — where `AudioEnginePreference.AUTO` always selects the Java engine — the entire Suite 2.2 protection is therefore absent, and this is exactly the OS the v1.2 crash fix targets.
- **Reproduction Steps**: 1) Run on Android 11 device. 2) Confirm settings badge shows "Platform Java (AudioRecord)". 3) Enable Feedback Suppression in Settings. 4) Induce acoustic feedback at high gain — no notch engages, no warning banner (`isFeedbackActive` never rises).
- **Root Cause & Recommended Remediation**: Feature implemented only in the native engine. Port the zero-crossing resonance detector + `BiquadFilter` notch into `SpeechDsp` (allocation-free, same 0.65/0.45 thresholds and 1.5 s hold) and wire `isFeedbackActive` through `JavaAudioEngine`; until then, document the limitation on the settings toggle.

- **ID**: QA-03
- **Severity**: P3 - Minor
- **Description**: `MicForegroundService.acquireWakeLock()` uses `acquire(120 * 60 * 1000L)` — a 2-hour hard cap. Broadcasts longer than 2 hours with the screen off lose the partial wake lock and may be throttled by Doze.
- **Reproduction Steps**: 1) Start broadcast. 2) Turn screen off. 3) Leave running > 2 h. 4) Observe potential CPU suspension of the PCM/UDP workers.
- **Root Cause & Recommended Remediation**: Safety-timeout pattern without renewal. Renew the wake lock periodically from the metering loop (or acquire unbounded and strictly release in `onDestroy`, matching the "release the wake lock" contract already in the docs).

- **ID**: QA-04
- **Severity**: P3 - Minor
- **Description**: For the Walkie-Talkie role, `MicForegroundService` starts with combined `FOREGROUND_SERVICE_TYPE_MICROPHONE or FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK`, diverging from `AGENTS.md` ("Never bitwise-combine …"). It is defensible for a role that simultaneously captures and plays, and matches the manifest declaration `foregroundServiceType="microphone|mediaPlayback"`, but the repository rule and code disagree.
- **Reproduction Steps**: 1) Read `MicForegroundService.startForegroundWithNotification()` WALKIE_TALKIE branch. 2) Compare with AGENTS.md §1 tenet 3.
- **Root Cause & Recommended Remediation**: Rule written for standard mic capture; walkie needs both. Amend AGENTS.md to allow combined types for WALKIE_TALKIE specifically, or split capture/playback services to keep single-type FGS.

- **ID**: QA-05
- **Severity**: P3 - Minor
- **Description**: When the user forces "Native C++ (Ultra Low-Latency)" on an unsupported HAL and the engine silently falls back to Java, the only user notification is the "Active Audio Stack" badge in Settings. Test plan 1.4 expects "graceful fallback to Java **with user notification**".
- **Reproduction Steps**: 1) Select Native C++ on a device whose HAL rejects the stream. 2) Start mic. 3) Note absence of any toast/snackbar/dialog; only the settings badge reads "Platform Java (AudioRecord)".
- **Root Cause & Recommended Remediation**: Fallback path (`AudioSessionManager.startFromService` catch block) only logs. Emit a one-shot `AudioState.Muted`-style banner or snackbar ("Native engine unavailable — using Platform Java") on the first fallback.

- **ID**: QA-06
